# Something Is Strange

Low-cost physical validation track for the TikTok-Native Game Experiment Factory.

Current scope is deliberately narrow: validate whether short dynamic anomaly puzzles create a strong stop-and-answer loop before investing in production infrastructure.

Initial proof levels:
1. Shadow Ahead
2. Late Mirror
3. Domino Break

Constraints: zero paid runtime dependencies, reusable data-driven puzzle structure, deterministic replay, tap-only interaction, fast reveal.
